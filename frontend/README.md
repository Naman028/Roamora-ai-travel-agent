# Roamora Frontend

Next.js 16 App Router frontend for Roamora.

## Setup

```bash
npm ci
```

Copy `.env.example` to `.env.local` and configure the server-only FastAPI connection.

## Commands

```bash
npm run dev
npm run lint
npm run typecheck
npm test
npm run build
npm run start
npm run test:e2e
```

Run all commands from this `frontend/` directory. The production build uses Next.js standalone output.
